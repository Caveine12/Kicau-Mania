# 🐦 Kicau-Mania

Website sederhana bertema dunia burung kicau yang dibuat menggunakan HTML dan CSS.

## ✨ Fitur
- Tampilan responsif
- Desain sederhana dan ringan
- Galeri foto burung
- Pemutar audio suara burung
- Tema warna modern

## 📂 Struktur Proyek

```
Kicau-Mania/
│
├── index.html
├── README.md
├── CSS/
│   └── style.css
├── Audio/
│   └── audio.mp3
└── Foto/
    └── foto.png
    └── background.jpg    
```

## 🚀 Cara Menjalankan

1. Clone repository ini:

```bash
git clone https://github.com/Caveine12/Kicau-Mania.git
```

2. Buka file `index.html` di browser.

## 🛠 Teknologi

- HTML5
- CSS3
